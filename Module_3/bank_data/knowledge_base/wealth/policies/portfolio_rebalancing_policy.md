# Portfolio Rebalancing Policy (v1.8)
Owner: Wealth Investment Committee · Applies to: all NovaBank Wealth staff

Client portfolios are reviewed every quarter. A portfolio is rebalanced when any asset class drifts more than 5
percentage points from the client's target allocation. Advisors must record the client's written consent before any
rebalancing trade. Model portfolios: Conservative (20% equity), Balanced (50% equity), Growth (75% equity).
