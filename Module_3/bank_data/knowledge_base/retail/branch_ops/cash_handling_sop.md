# Branch Cash Handling SOP (v5.0)
Owner: Branch Operations · Applies to: branch operations staff

The vault must be opened by two officers together (dual control). Teller cash limit is Rs 5 lakh; excess cash
must be moved to the vault within 30 minutes. Cash deposits of Rs 50,000 or more need the customer's PAN.
Counterfeit notes must be impounded and a report filed with the branch manager the same day.
At end of day the cash position must be balanced and signed by the teller and the cash officer.
